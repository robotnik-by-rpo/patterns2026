# Основные сущности в проекте

|Наименование сущности | Описание   | Связи с другими сущностями|
|----------------------|------------|---------------------------|
|Единица измерения|Единица измерения для других сущностей|Ингредиенты, блюдо, склад|
|Деньги|Денежный эквивалент сущностей с указанием валюты|Ингредиент, блюдо, контракт, заказ|
|Ингредиент|Продукт питания, входящий в состав блюда|Склад, блюдо, технологическая карта|
|Адрес доставки|Место, по которому выполняется доставка заказа клиенту|Заказ|
|Сотрудник|Работник компании одной из трех категорий: производство, обслуживание, управление|Ресторан, график работы, контракт, группа|
|Контрагент|Юридическое лицо, физическое лицо, индивидуальный предпрениматель, с которым организация ведет бизнес|Контракт, группа|
|Группа|Общность людей, связанных одним признаком|Сотрудник, контрагент, ингредиент|
|Блюдо|Итоговый продукт из ингредиентов, изготовленный по технологической карте|Технологическая карта, заказ|
|Технологическая карта|Набор инструкций для приготовления блюда|Блюдо, ингредиент, технологическая карта|
|Склад|Место хранения ингредиентов|Ресторан, ингредиент|
|Ресторан|Точка продаж компании|Сотрудник, склад, график работы, заказ|
|Контракт|Документ, связывающий условиями контрагента и сотрудника|Контрагент, сотрудник, деньги|
|График работы|Правила времени работы|Сотрудник, ресторан|
|Заказ|Потребность клиента|Блюдо, сотрудник, ресторан, адрес доставки|
